# เฉลยแบบฝึกหัด

> ⚠️ **ลองเองก่อนอย่างน้อย 15 นาที** ก่อนเปิดเฉลย — สมองจำสิ่งที่เคยติดขัดได้ดีกว่าสิ่งที่อ่านผ่านตา

## วิธีใช้ให้ได้ผล

1. ลองเองก่อน ติดแล้วค่อยเปิด
2. เปิดแล้ว **อย่าก็อปวาง** — ปิดเฉลยแล้วพิมพ์เองใหม่
3. อ่านหัวข้อ **"ทำไมถึงเป็นแบบนี้"** ให้จบ คำสั่งลืมได้ แต่เหตุผลอยู่กับเราตลอด
4. ทำหัวข้อ **"ต่อยอด"** ถ้ามี

## หมายเหตุเรื่องระดับ 4–5

โจทย์ระดับ 4–5 หลายข้อ **ไม่มีคำตอบเดียวที่ถูก** — เป็นการตัดสินใจเชิงออกแบบที่ขึ้นกับบริบทของระบบคุณ
เฉลยของสองระดับนี้จึงเป็น **แนวคำตอบ + เกณฑ์ประเมินตัวเอง** ไม่ใช่คำตอบสำเร็จรูป
ถ้าคำตอบคุณต่างจากเฉลยแต่มีเหตุผลรองรับด้วยข้อมูลจริง — นั่นคือคำตอบที่ดีกว่า
