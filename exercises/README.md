# แบบฝึกหัด DevOps

แบบฝึกหัดทั้งหมดใช้โปรเจกต์ `devops-todo-api` ในโฟลเดอร์นี้เป็นสนามซ้อม
แยกตามหัวข้อ แต่ละหัวข้อไล่จาก **ระดับ 1 (เริ่มต้น) → ระดับ 5 (มืออาชีพ)**

## ระดับความยาก

| ระดับ | ชื่อ | คุณทำอะไรได้เมื่อผ่านระดับนี้ | เวลาโดยประมาณ |
| --- | --- | --- | --- |
| 🟢 1 | เริ่มต้น | รันคำสั่งเป็น อ่าน config ออก รู้ว่าอะไรอยู่ตรงไหน | 1–2 ชม. |
| 🔵 2 | พื้นฐานแน่น | แก้ config เองได้ พิสูจน์พฤติกรรมของระบบด้วยการทดลอง | 2–4 ชม. |
| 🟡 3 | ใช้งานจริง | ตั้งค่าให้ปลอดภัยและพร้อมขึ้น production | 4–8 ชม. |
| 🟠 4 | ขั้นสูง | จูนประสิทธิภาพ แก้ปัญหาที่ซับซ้อน ใช้ฟีเจอร์ลึก | 1–2 วัน |
| 🔴 5 | มืออาชีพ | ออกแบบ ตัดสินใจเชิงสถาปัตยกรรม และอธิบายเหตุผลได้ | 2–5 วัน |

## เส้นทางการฝึก

```
Docker ระดับ 1-2  ──▶  Nginx ระดับ 1-2  ──▶  CI/CD ระดับ 1-2
      │                                              │
      ▼                                              ▼
Docker ระดับ 3-4  ──▶  Nginx ระดับ 3-4  ──▶  Kubernetes ระดับ 1-3
                                                     │
                                                     ▼
                              ทุกหัวข้อระดับ 4-5 (เลือกตามงานที่ทำจริง)
```

**อย่าไล่ Docker ให้จบระดับ 5 ก่อนแตะ Nginx** — ทำระดับ 1-2 ให้ครบทุกหัวข้อก่อน แล้วค่อยไต่ระดับพร้อมกัน จะเห็นภาพรวมเร็วกว่ามาก

## เฉลย

อยู่ใน [`solutions/`](solutions/) แยกไฟล์ตรงกับแบบฝึกหัดทุกไฟล์

**วิธีใช้เฉลยให้ได้ผล:**

1. ลองเองก่อนอย่างน้อย 15 นาที — ติดแล้วค่อยเปิด
2. เปิดเฉลยแล้ว **อย่าก็อปวาง** ให้ปิดเฉลยแล้วพิมพ์เองใหม่
3. อ่านหัวข้อ "ทำไมถึงเป็นแบบนี้" ให้จบ — คำสั่งจำได้ไม่กี่วันก็ลืม แต่เหตุผลอยู่กับเราตลอด
4. ทำข้อ "ต่อยอด" ท้ายเฉลยด้วย ถ้ามี

## รูปแบบของแต่ละข้อ

```
### D2.1 ชื่อโจทย์
**โจทย์:**   สิ่งที่ต้องทำ
**คำใบ้:**   ทางไปต่อเมื่อติด (ไม่ใช่คำตอบ)
**ผ่านเมื่อ:** เกณฑ์ที่วัดได้ — ถ้าทำข้อนี้แล้วเช็คไม่ได้ตามนี้ แปลว่ายังไม่ผ่าน
```

ช่อง **ผ่านเมื่อ** สำคัญที่สุด เพราะมันบังคับให้เราพิสูจน์ ไม่ใช่แค่ "รู้สึกว่าน่าจะได้แล้ว"

## เตรียมเครื่องก่อนเริ่ม

```bash
cd devops-todo-api
cp .env.example .env
npm install
docker compose up -d --build
curl http://localhost:8080/healthz     # ต้องได้ 200 ก่อนถึงเริ่มฝึกได้
```

ระดับ 3 ขึ้นไปของ Kubernetes ต้องมีคลัสเตอร์ในเครื่อง (minikube / kind / Docker Desktop) — ดู [docs/08](../docs/08-kubernetes.md)
